# GoHereSDK Swift Package

## Requirements
* [iOS 14.5](https://wikipedia.org/wiki/IOS_14) or later.

## Installation
- Add the following dependency to your project's `Package.swift`.

```swift
dependencies: [
    .package(url: "https://github.com/pinchbv/gohere-sdk-ios.git", .upToNextMinor(from: "1.0.0"))
]
```

## Documentation

GoHere SDK documentation has been created using DocC, please refer to the GoHereSDK.doccarchive for more information on how to use the SDK.
